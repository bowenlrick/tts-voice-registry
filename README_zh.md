# Voice Model Registry

一个面向社区音色模型的开放注册库，提供标准化的元数据、来源信息、兼容性信息和许可信息。

> **状态：** 早期开发阶段  
> 注册库格式和贡献指南目前仍在设计中。

## 关于项目

Voice Model Registry 旨在提供一种结构化且透明的方式，用于发布、发现和分享社区创建的音色模型。

本项目并非只是一个模型文件合集。每个音色条目都会记录如下信息：

- 框架和模型版本
- 模型类型和架构
- 支持的语言
- 模型文件及其校验值
- 训练数据来源
- 音色 / 说话者授权状态
- 模型和相关素材的许可证
- 兼容性信息
- 下载位置
- 版本历史

本项目的目标是让社区音色模型更易于使用、验证、维护，并以负责任的方式进行再分发。

本注册库旨在支持不同的音色模型架构，而不要求所有框架使用相同的模型格式。

## 框架支持

初步计划支持：

| 框架 | 类型 | 状态 |
| --- | --- | --- |
| GPT-SoVITS | TTS / 音色克隆 | 🚧 计划支持 |
| RVC | 语音转换 | 未来支持 |
| Fish Speech | TTS / 音色克隆 | 未来支持 |
| OpenVoice | TTS / 语音转换 | 未来支持 |
| 其他框架 | — | 欢迎贡献 |

不同框架所使用的模型文件格式可能完全不同。

因此，本注册库标准化的是元数据和来源信息，而不是试图定义一种通用的模型 checkpoint 格式。

├── registry/           # 音色模型元数据
│   └── <voice-id>/
│       ├── manifest.yaml
│       └── README.md
│
├── schema/             # 注册库元数据 Schema
├── scripts/            # 验证和维护工具
├── docs/               # 文档
│
├── CONTRIBUTING.md
├── MODEL_POLICY.md
├── LICENSE

大型模型文件不计划直接存储在这个 Git 仓库中。

模型 checkpoint 可以托管在 Hugging Face、GitHub Releases 等服务上，并由对应的注册库条目引用。

## 音色 Manifest

每个已注册的音色都将包含一个机器可读的 manifest，用于描述该音色模型及其相关元数据。

示例：

~~~yaml
schema_version: 1

id: example-voice
name: Example Voice

status: released

engine:
  family: GPT-SoVITS
  version: example-version

model_type:
  - tts
  - voice-cloning

languages:
  - zh-CN

voice:
  type: original
  real_person_clone: false

artifacts:
  - type: model
    filename: example.pth
    sha256: "..."

provenance:
  training_data_source: original_or_authorized

licenses:
  model: MIT
  training_data: restricted
  artwork: null
~~~

该 Schema 目前仍在开发中，在首个稳定版本发布之前可能会发生变化。

不同框架可以定义额外的框架专属模型文件字段，同时保留注册库的通用元数据。

## 模型来源与许可

本仓库的许可证**不会**自动适用于单独的音色模型、数据集、参考音频、角色美术素材或其他第三方资产。

每个音色条目都必须声明其相关的许可信息和来源信息。

具体来说：

- 框架本身的许可证不会自动决定使用该框架训练出的音色模型采用何种许可证。
- 可以公开获取的音频并不自动意味着该音频已获得用于音色模型训练或再分发的授权。
- 基于可识别真实人物的模型必须提供适当的授权信息。
- 角色美术素材和其他资产可能使用与音色模型不同的许可证。
- 贡献者有责任确保自己拥有分发所提交材料所需的权利。
- 模型不得声称其创建者实际上并不拥有的权利或许可。
- 模型被收录进本注册库并不意味着该模型的所有可能用途在法律上都被允许。

完整的模型提交政策请参阅 `MODEL_POLICY.md`。

## 计划中的首个音色

计划中的首个实验性条目是使用 GPT-SoVITS 创建的社区音色 **Whale Girl / 鲸鱼娘**。

该音色模型将作为非官方社区项目进行开发。

本项目与 DeepSeek 不存在隶属、赞助或官方认可关系。

计划中的音色将作为社区原创音色开发，而不是对任何可识别真实人物声音的克隆。

模型文件、来源信息、兼容性信息和许可细节将在训练与评估完成后发布。

## 贡献

本项目目前仍处于初始设计阶段。

欢迎贡献代码、提出建议、提交 Schema 方案、添加框架集成，以及讨论音色模型之间的互操作性。

在提交音色模型之前，贡献者需要提供充分的信息，包括：

- 模型框架和版本
- 模型来源
- 训练数据来源
- 音色 / 说话者授权信息
- 适用的许可证
- 所需的模型文件
- 文件校验值
- 已知的兼容性要求

贡献指南将在 `CONTRIBUTING.md` 中提供。

## 托管方式

本仓库的主要作用是作为注册库，而不是大型文件托管服务。

计划采用如下结构：

~~~text
GitHub
├── 注册库元数据
├── Schema
├── 文档
├── 验证工具
└── 版本历史

外部模型托管
├── 模型 checkpoint
├── 框架专属模型文件
├── 可选的参考音频
└── 其他大型文件
~~~

模型的托管位置将由对应的音色 manifest 引用。

## 许可证

除非另有说明，专门为本仓库创建的源代码、Schema、文档和工具均根据 [MIT License](LICENSE) 授权。

单独的音色模型、训练数据集、参考音频、美术素材、角色资产及其他第三方材料可能使用不同的许可证。

用于训练或运行模型的框架所采用的许可证，并不会自动决定训练所得模型采用何种许可证。

在使用、修改或再分发任何音色模型之前，请始终检查对应的音色 manifest。
